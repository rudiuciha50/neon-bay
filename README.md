A complete top-down open-world crime game built for the [make.fun GTA6-01](https://make.fun/bounty/gta6-01) bounty.

## Features
- Procedurally generated city with road grid, buildings, parks, and water
- Player on foot (WASD+mouse) and driving (car physics)
- Traffic AI following roads, pedestrian AI wandering/fleeing
- Police system with wanted levels 1-5 stars
- 5-mission story campaign
- Combat with pistol shooting, melee, reload system
- Web Audio API sound effects (gunshots, engine, sirens)
- HUD with health bar, wanted stars, money, minimap
- Start screen, pause, game over, localStorage save
- Particle effects and screen shake

## Run
```bash
cd game && python3 -m http.server 8080
```
Open http://localhost:8080 in Chrome.
